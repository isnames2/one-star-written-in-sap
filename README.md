A houseplant's one-star review of its human, written for the make.fun
competition "One Star, Written in Sap".

Bounty: https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4

`main.py` (pure Python standard library) writes the review to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> One star. He bought me for the sunny windowsill, then hung blackout
> curtains for 'ambience' — I now photosynthesize purely out of spite.
